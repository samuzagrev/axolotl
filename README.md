**Por Samu Zagrev · Editorial Zagrev · 2024**

## Cómo publicar este sitio (5 minutos)

### Opción rápida — Netlify Drop
1. Entra a https://app.netlify.com/drop
2. Arrastra esta carpeta completa (no el .zip, descomprime primero) sobre la ventana
3. Te da una URL al instante (ej. `random-name-12345.netlify.app`)
4. Crea cuenta gratis para conservarla y poder cambiar el nombre del subdominio

### Para cambiar el subdominio
- Dentro de Netlify → Site settings → Change site name
- Pon algo como `samuzagrev` o `el-viaje-de-axolotl`
- Tu URL final será `samuzagrev.netlify.app`

### Si quieres dominio propio (ej. samuzagrev.com)
- Compra el dominio en Namecheap o GoDaddy (~$200 MXN/año)
- En Netlify → Domain settings → Add custom domain
- Sigue las instrucciones (tarda 10-30 min en propagarse)

## Qué contiene esta carpeta

- `index.html` — el sitio
- `favicon.ico` — el iconito que sale en la pestaña
- `apple-touch-icon.png` — icono para iPhone cuando guarden el sitio
- `img/` — las 22 ilustraciones + el preview para redes sociales (og-preview.jpg)
- `robots.txt` — permite a Google indexar el sitio

## Para actualizar contenido
- Edita `index.html` con cualquier editor de texto
- Re-arrastra la carpeta a Netlify (si ya tienes cuenta, se actualiza solo)
